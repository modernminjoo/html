보도자료 HTML 정리기

한글(HWP)에서 복사한 보도자료의 글꼴·크기·여백 서식을 걷어내고, 스크린리더와 전자점자가 읽기 좋은 게시판용 HTML로 바꿉니다. 글자 내용은 바꾸지 않습니다.

알아두기

  • 이미지는 직접 넣어야 합니다. 노란 표시 위치에 게시판 에디터로 이미지를 넣고 대체텍스트(사진 설명)를 꼭 입력하세요.
  • 목록 단계를 확인하세요. 기호가 처음 나온 순서(보통 □ → ○ → - → ·)로 단계를 정하므로 미리보기에서 맞는지 봐주세요.
  • 내용은 외부로 나가지 않습니다. 붙여넣은 내용은 이 브라우저 안에서만 처리되고 저장·전송되지 않습니다.
  1. 1한글에서 Ctrl+A, Ctrl+C
  2. 2이 화면에서 Ctrl+V
  3. 3확인할 점 점검 후 코드 복사
  4. 4게시판 HTML(소스) 모드에 붙여넣기
